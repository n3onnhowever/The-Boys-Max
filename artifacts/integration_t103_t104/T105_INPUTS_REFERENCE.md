# T105 inputs reference

Accepted input list: `docs/handoffs/T105_INPUTS_FROM_T104.md`.

It covers:

- conditional price, mandatory extras, raw text, evidence scope and strict budget semantics;
- large/recurring/range/conflicting/sentinel dates, null end, occurrence identity and reconciliation;
- null place/coordinates and no fake point;
- body size, latency, pagination and revised timeout assumptions;
- `actual_since` semantics, partial sync, cancellation/update uncertainty and checkpoints;
- source URL, `fetched_at`, receipt/hash and lawful minimal evidence.

This reference does not start T105 or define a schema/code implementation.
