# ADR-004 — KudaGo is a conditional primary provider
Status: OPEN GATE

Decision:
KudaGo is the primary technical candidate, NOT production-approved.

Approval requires:
- canonical runtime data gate;
- zero critical false PASS;
- legal/manual decision for actual MAX use, source-link/indexability, advertising material handling and any required storage/cache/history/images.

No silent fallback provider is allowed.
