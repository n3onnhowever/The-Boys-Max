# ADR-001 — Frozen solo-first P0 and evidence-first delivery
Status: ACCEPTED

Decision:
- Keep the frozen solo-first Moscow P0.
- Social, Smart Povod, second city and map cannot block core.
- Research does not change P0 silently.
- Runtime claims require artifacts from an identified release SHA.

Consequences:
- New features default to P1/Stretch.
- Presentation claims follow evidence, not roadmap.
