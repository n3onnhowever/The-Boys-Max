# ADR-007 — Occurrence-first honest UX
Status: ACCEPTED

Keep:
- Poster Pop brand, calm operational UI;
- Для тебя / Поиск / Сохранённые;
- source/provenance;
- explicit typed UNKNOWN;
- conditional price;
- Save != Follow != Going/commitment.

Do not:
- show fake freshness;
- use unknown price as free/zero;
- fabricate coordinates/end time;
- show opaque AI match percentages;
- make map/social a mandatory P0 navigation path.
