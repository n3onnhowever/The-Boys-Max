# Каталог KudaGo для хакатона

## Состав выпуска

- `curated-kudago-moscow-a-v1.json` и `curated-kudago-moscow-b-v1.json`: 150 будущих московских сеансов из публичного API KudaGo.
- Распределение: 50 театров, 40 концертов, 19 музеев и выставок, 7 кинопоказов, 34 прочих события.
- Сеансы идут с 30 сентября по 14 декабря 2026 года.
- В приложении источник на таких карточках явно подписан `KudaGo` и ведёт на страницу события.

## Правила данных

- Оставлены только записи с опубликованными будущими датой и временем.
- Исключены бессрочные, непрерывные и повторяющиеся расписания.
- Не копируются описания и изображения KudaGo: в карточках используются локальные оригинальные иллюстрации категорий.
- Цена сохраняется только как исходный текст KudaGo; неизвестные доплаты остаются неизвестными.

## Развёртывание

`amvera.yaml` импортирует исходный каталог Дарвиновского музея, проверенный набор Третьяковской галереи и два файла KudaGo до старта приложения. Хост KudaGo добавлен в разрешённые источники и ссылки.

## Ограничение

Спортивных и outdoor-сеансов с точной будущей датой в полученном ответе API не было. В этих разделах остаются явно маркированные демо-карточки приложения.
